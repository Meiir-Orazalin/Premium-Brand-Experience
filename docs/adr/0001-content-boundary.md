# 0001 · Server-side content adapters

Accepted for the vertical slice. Both fixtures and Sanity implement one typed repository. Select the adapter explicitly by environment. A failed live query reaches the route error boundary. Preview uses isolated credentials and uncached queries.

A CMS-only application would block local and CI work on a dataset. Embedding fixture branches in page components would make the two rendering paths diverge. The shared contract costs adapter tests and schema maintenance, and lets the same UI handle either source. Live permissions, visual editing and revalidation still need integration verification before release.
