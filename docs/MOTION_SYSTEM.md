# Motion system

Keep essential server-rendered content visible. Target 150–350 ms for microinteractions, 200–400 ms for hover and 600–1000 ms for text. Test route entry around 700–1200 ms without delaying navigation. Validate the prototype with native links, direct loads, rapid navigation, errors, keyboard, history and scroll restoration.

Scope useGSAP and responsive matchMedia to mounted features. Revert timelines, ScrollTriggers, timers and listeners. Share one ticker between Lenis and GSAP. Refresh triggers on meaningful geometry changes. Use SplitText with a single accessible reading order and Flip for category changes where justified. Suspend offscreen automatic playback. Provide pause and reduced-motion alternatives.
