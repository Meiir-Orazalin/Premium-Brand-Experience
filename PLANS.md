# Execution plans

Maintain docs/plans/phase-XX.md as the working record for the active phase. Include objective, current context, actionable tasks and milestones, testable acceptance criteria, validation commands, progress checklist, decisions, discoveries, blockers, recovery steps and outcomes. Update the record when evidence or scope changes. Include enough context to resume from a fresh clone. Use pending checkboxes until verified. Record external results by reference after publication. Git and the checks API are authoritative for SHAs and CI.
